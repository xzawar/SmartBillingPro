Libraries used by Smart Billing Pro (all run fully offline, bundled here so
no download is needed to build or run the app):

  sqlite-jdbc-3.53.2.0.jar   SQLite database driver            Apache 2.0
  flatlaf-3.5.4.jar          Modern Swing look and feel        Apache 2.0
  pdfbox-3.0.3.jar           PDF receipts and reports          Apache 2.0
  pdfbox-io-3.0.3.jar        (PDFBox dependency)               Apache 2.0
  fontbox-3.0.3.jar          (PDFBox font support)             Apache 2.0
  commons-logging-1.3.4.jar  (PDFBox dependency)               Apache 2.0

The run/build scripts put every .jar in this folder on the classpath.
